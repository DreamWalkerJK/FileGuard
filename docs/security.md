# 安全边界与平台限制

FileGuard 读取和修改由服务进程权限决定的本地文件。它不是权限提升工具，也不会把浏览器本地磁盘上传到服务端。所有测试使用专用临时目录；不要把真实用户路径、清单、日志或数据库提交到公开仓库。

## 访问控制

Web 默认只绑定 localhost，使用启动时生成的本地凭据建立会话。凭据位于数据目录的 `web-private/startup-token.txt`，Windows 限制当前用户和 SYSTEM 访问；成功登录后删除一次性 token，会话最多持续 8 小时，重启生成新 token。所有变更请求必须有认证会话、CSRF 令牌和合法 Host/Origin。服务端允许根目录列表限制扫描范围；HTTP 参数不能把服务扩展为任意磁盘浏览器。首版拒绝远程监听，若将来开放远程访问，必须显式配置认证和 HTTPS。没有任意文件下载端点，也不会将扫描内容上传外部服务。普通日志使用任务 ID、相对路径或错误类别；本地诊断模式才可记录绝对路径。

## 路径、链接与竞态

清单和计划路径必须是规范相对路径，拒绝绝对路径、`..`、盘符、UNC、alternate data stream 及根外解析结果。默认不跟随 symlink、junction 或 reparse point。文件执行前重新验证最终路径、祖先目录链接状态、文件身份、大小与摘要。扫描结果不是原子快照；扫描期间文件可以消失或变更，结果会标记不可读/不稳定。

只做字符串前缀比较不足以防止 TOCTOU。Windows 修改操作在最终操作期间持续持有候选、保留项和祖先目录的句柄，禁止写入/删除共享，复核最终句柄路径和 OS 文件 ID，并用句柄完成 rename 或 delete；无法证明最终对象仍是计划对象时保守拒绝。Linux 读取使用 O_NOFOLLOW、最终文件句柄路径边界验证和流式摘要，物理身份/硬链接数量未知，修改被拒绝。macOS 当前没有安全读取后端，逐项读取会明确失败，不能宣称支持。

允许根目录的路径拼写（包括大小写）要求与扫描路径一致，以防 Windows 大小写敏感子目录造成边界混淆。Windows 大小写敏感目录允许读取，修改采取保守拒绝。UNC/设备路径、备用数据流、以点或空格结尾的歧义 Windows 路径均不支持。

普通文件如果带有命名 alternate data stream（例如 Zone.Identifier）也会标记不可安全读取并拒绝清理，不能只比较未命名主数据流后声称两个文件完全相同；这样也避免跨卷复制时静默丢失额外流。首版不提供数据流清单或流迁移。

硬链接共享物理对象，不能把每个名字都算作可回收容量。稀疏文件、压缩、去重、快照、写时复制和其他硬链接会使逻辑字节与实际物理空间不同。隔离是可恢复移动，通常不会释放空间；预计值未知时必须显示未知。

## 清单与哈希

SHA-256 用于内容一致性和重复确认，不证明来源真实性。清单编码、排序和 schema 规则见 [manifest-format.md](manifest-format.md)。文件在哈希前后状态变化会标记不稳定。局部采样、大小、时间戳和文件名不能独立证明完全重复。

## 目前明确限制

* 首版没有清单数字签名、远程 Web、自动永久删除计划或跨平台安全修改保证。
* 重启后若任务没有持久化检查点，只能识别中断并重新扫描；不能声称从中断位置续扫。
* Windows 网络 UNC、设备路径不支持；FUSE、虚拟文件系统或旧 Windows 文件系统可能没有可靠文件 ID、原子 rename 或链接信息，工具会降级为未知、跳过或拒绝。
* Windows 长路径支持取决于系统长路径策略和运行时；超出平台限制时记录明确错误。
* 物理回收空间无法仅从逻辑长度推算，尤其在快照、压缩、稀疏、去重或共享块场景。

任何尚未在目标平台实测的能力都必须在测试报告中列为未验证，不得用模拟结果代替声明。
